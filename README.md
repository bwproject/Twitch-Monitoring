## ✨ Возможности

- 📡 **Мониторинг Twitch** — отслеживание начала и завершения трансляций, смены названия и категории.
- 🔔 **Уведомления сразу на нескольких платформах** — Telegram, Discord и Lolka. Поддержка других социальных сетей находится в разработке.
- 💬 **Twitch Chat Bot** — отдельный чат-бот с командами и настраиваемым префиксом.
- 🌐 **Публичная главная страница** — список подключённых стримеров с текущим статусом каналов.
- 🔴 **Карусель прямых эфиров** — превью активных трансляций, название, категория и количество зрителей. Список и превью автоматически обновляются.
- 🛠️ **Веб-админка** — управление стримерами, настройками уведомлений, пользователями и интеграциями.
- 📋 **Заявки на подключение** — зрители и стримеры могут отправить заявку через сайт.
- 📱 **Telegram Mini App** — управление собственными настройками Twitch-уведомлений.
- 🧩 **Независимые компоненты** — сбой одного бота не должен останавливать остальные части приложения.

## 🖥️ Веб-интерфейс

| Адрес | Назначение |
|---|---|
| `/` | Главная: подключённые стримеры, статусы каналов и карусель эфиров |
| `/apply` | Форма заявки на подключение |
| `/admin` | Вход в браузерную панель администратора |
| `/twitch/` | Telegram Mini App |
| `/status` | Публичный статус основных компонентов |

Веб-сервер по умолчанию слушает `0.0.0.0:1047`. Порт и адрес можно изменить через переменные окружения.

## 🔔 Система уведомлений

Сервис поддерживает три платформы:

- **Telegram** — уведомления в выбранные чаты и каналы.
- **Discord** — отдельный бот для отправки уведомлений на Discord-сервер.
- **Lolka** — отдельный бот для отправки уведомлений в каналы Lolka.

Для каждого стримера можно настроить получателей и шаблоны сообщений. Доступны события:

- начало трансляции;
- изменение названия;
- изменение категории / игры;
- завершение трансляции.

Можно подключать канал только к отдельным платформам — Telegram не обязателен, если нужны только Discord или Lolka. Поддержка дополнительных социальных сетей планируется.

## 🔐 Пользователи и права доступа

В веб-панели предусмотрены две основные роли:

| Возможность | `admin` | `user` |
|---|:---:|:---:|
| Просмотр и редактирование всех стримеров | ✅ | — |
| Редактирование назначенных стримеров | ✅ | ✅ |
| Управление токенами и интеграциями | ✅ | — |
| Управление пользователями и ролями | ✅ | — |
| Просмотр и обработка заявок | ✅ | — |
| Изменение собственных настроек назначенных каналов | ✅ | ✅ |

Права проверяются на сервере по актуальной записи пользователя. Роль и список доступных каналов из старой сессии не считаются источником разрешений.

Telegram Mini App проверяет подпись `initData` и владельца канала по Telegram ID. Клиент не может самостоятельно подменить идентификатор владельца.

## 🚀 Установка и запуск

### Требования

- Python **3.12 или новее** (в том числе Python 3.14).
- Twitch Client ID и Client Secret для Twitch Helix API.
- Токены Telegram, Discord и Lolka — только для тех интеграций, которые планируется использовать.

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### Настройка окружения

Создайте файл `.env` на основе [`.env.example`](.env.example):

```bash
cp .env.example .env
```

Заполните необходимые параметры:

```dotenv
# Twitch Helix API — необходимы для мониторинга каналов
TWITCH_CLIENT_ID=
TWITCH_CLIENT_SECRET=

# Telegram — если нужен Telegram-бот и Telegram Mini App
TELEGRAM_TOKEN=

# Twitch Chat Bot — отдельный компонент
TWITCH_BOT_NICK=
TWITCH_BOT_ID=
TWITCH_OAUTH=
TWITCH_CHAT_PREFIX=!

# Discord и Lolka — необязательные интеграции
DISCORD_BOT_TOKEN=
LOLKA_BOT_TOKEN=

# Мониторинг и веб-сервер
CHECK_INTERVAL=30
WEB_HOST=0.0.0.0
WEB_PORT=1047
WEB_COOKIE_SECURE=false

# Каталог постоянных данных
BOT_DATA_DIR=data
```

Пароль администратора и пользователей можно задать через переменные `WEB_ADMIN_*` и `WEB_USER*_*` при первоначальной настройке. В рабочей установке учётные записи хранятся в `data/admin/users.json`.

> **Важно:** не публикуйте `.env`, токены, пароли и каталог `data/`. Для работы админ-панели через HTTPS установите `WEB_COOKIE_SECURE=true`.

### Запуск

```bash
python main.py
```

### Каталог данных

Изменяемые данные отделены от исходного кода и размещаются в `BOT_DATA_DIR` (по умолчанию `data/`):

| Путь | Содержимое |
|---|---|
| `data/twitch/streamers.json` | Основной список стримеров |
| `data/twitch/streamers/<login>.json` | Настройки конкретного канала и шаблоны |
| `data/twitch/cache.json` | Кэш Twitch |
| `data/twitch/chat/` | Настройки Twitch Chat Bot и команды |
| `data/admin/` | Пользователи, сессия и настройки интеграций |
| `data/applications.json` | Заявки с сайта |

При первом запуске `paths.py` переносит старые корневые JSON-файлы в новую структуру, только если целевой файл ещё не существует. Уже существующие файлы в `data/` не перезаписываются.

Старые корневые модули совместимости (например, `admin.py`, `chat.py`, `twitch_api.py`, `webapp.py`) оставлены для старых импортов. Новую разработку следует вести в соответствующих пакетах `bot/`, `twitch/` и `web/`.

## 🧱 Независимая работа компонентов

Компоненты запускаются независимо друг от друга:

- отсутствие `TELEGRAM_TOKEN` пропускает Telegram polling, но не должно останавливать мониторинг и другие интеграции;
- ошибка Telegram не блокирует Discord, Lolka и веб-интерфейс;
- отсутствие `DISCORD_BOT_TOKEN` не мешает остальным компонентам;
- отсутствие `LOLKA_BOT_TOKEN` не мешает остальным компонентам;
- Twitch Chat Bot пропускает запуск, если не заданы необходимые учётные данные.

Для мониторинга Twitch необходимы `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.

## 🔔 Личные подписки на стримеров

На главной странице у каждого подключённого Twitch-канала есть кнопка **«Отслеживать»**. Она показывает команды для личной переписки с ботами:

| Платформа | Подписаться | Отписаться | Список |
|---|---|---|---|
| Telegram | `/follow ИМЯ` | `/unfollow ИМЯ` | `/follows` |
| Discord | `!follow ИМЯ` | `!unfollow ИМЯ` | `!follows` |
| Lolka | `!follow ИМЯ` | `!unfollow ИМЯ` | `!follows` |

Перед отправкой команды откройте личную переписку с ботом и нажмите Start/отправьте ему сообщение. Личные подписки независимы от уведомлений в общих чатах. Уведомления приходят о начале эфира, смене названия, смене категории и завершении трансляции.

Подписки хранятся в `data/personal_subscriptions.json` и не требуют ручного редактирования конфигурации стримера.

## 🛡️ Безопасность и резервное копирование

- Храните секреты только в `.env` или защищённых настройках интеграций.
- Не добавляйте runtime-каталог `data/` в Git.
- Регулярно сохраняйте резервную копию `data/` перед обновлениями.
- Используйте HTTPS для публичной админ-панели и включайте `WEB_COOKIE_SECURE=true`.
- Не используйте одинаковые пароли для разных учётных записей.

## 🧰 Разработка

1. Создайте отдельную ветку для изменений.
2. Установите зависимости из `requirements.txt`.
3. Проверьте запуск через `python main.py`.
4. Не добавляйте реальные токены, пользовательские данные и runtime-файлы в коммиты.
