＋ Добавить Twitch-канал

Введите Twitch-логин или ссылку на канал. Мы проверим канал через Twitch API и добавим его в мониторинг. Новые каналы подхватываются мониторингом автоматически примерно за 5 секунд.

Добавление доступно только администраторам.

Данные Telegram, Twitch, Discord и Lolka

Доступно только администратору. Discord и Lolka можно подключать дополнительно. ID каналов здесь используются по умолчанию, если для стримера не задан отдельный ID в его настройках. Секреты сохраняются в data/admin/integrations.json на сервере и не возвращаются в браузер. Пустое поле не изменяет сохранённое значение.
